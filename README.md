# Mohamed Hany — Personal Portfolio

A responsive portfolio and four standalone practice projects built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Use the project cards to open each project.

## Projects
- **CoffeeCraft** — links to the existing GitHub repository: https://github.com/mo7amved/-CoffeeCraft
- **GreenBite Catering** — responsive catering website with a client-side demo booking form. It does not send data to a real business.
- **FocusList Task Manager** — add, complete, filter, delete, and clear tasks. Tasks persist in browser Local Storage.
- **SkyCast Weather** — city search and five-day forecast powered by Open-Meteo. Requires internet access; no API key required.
- **Nova Landing Page** — fictional productivity product landing-page concept. Pricing and product details are illustrative, not a real commercial offer.

## Before publishing
- Add your actual LinkedIn URL in `script.js` at the portfolio root.
- Confirm project details and update the portfolio copy to match what you personally completed.
- CoffeeCraft currently links to the existing GitHub repository; its source files are not duplicated in this bundle.
